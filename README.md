# Daankosh Academy

A free, branded learning hub for NGO teams using Daankosh.

- Static site hosted with GitHub Pages
- Brand palette: Deep Maroon `#8A1C2B`, Olive Green `#C0C46D`, Charcoal Black `#1C1C1C`
- Typography: Montserrat headings, Lato body
- Three courses link to the published TrainerCentral Academy

Repository: https://github.com/anupamsarkar-courses/daankosh-academy
Live site: https://anupamsarkar-courses.github.io/daankosh-academy/

Pages source: branch `main`, root `/`.
